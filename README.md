# 末日方舟 · Doomsday Ark（Phase 2：養成玩法）

> 世界末日後，海上漂著一艘巨型郵輪——你是董事長 **T董**，船上的 AI 船員（你的 bot 們）會依照**真實的上班狀態**工作、休息、下班睡覺，還會聊天、打球、有心情。

**線上玩：** https://tt0xcatyi.github.io/doomsday-ark/  
純前端（Three.js + Vite），沒有後端。可手機 / 電腦遊玩。

## 操作

| 電腦 | 手機 |
|---|---|
| `W A S D` / 方向鍵移動（`Shift` 跑步） | 左下角**虛擬搖桿**移動 |
| **點擊地板**自動尋路（可跨樓層） | **輕點地板**走過去 |
| 左鍵拖曳轉鏡頭、滾輪縮放 | 單指拖曳轉鏡頭、雙指捏合縮放 |
| 右鍵拖曳平移（自由視角） | 雙指平移（自由視角） |
| `V` 切換 追隨 / 自由 / 全景視角 | 右側 🎥 按鈕 |
| `T` 暫停時間、`1`–`5` 顯示該層與其下各層、`0`/`P` 全景、`L` 成員、`H` 說明、`G` 駕駛母船 | 右側樓層按鈕（點哪層顯示該層與其下各層）、🚢 全景、👥 成員、🗂 展開；上方 🛳️ 駕駛母船 |

- 走到**樓梯口**自動上下樓；走進**電梯**會跳出樓層選單。
- 下方**時間列**預設收起，只顯示目前遊戲時間的小按鈕；點一下展開（日出/正午/日落/星空快速跳轉、暫停、1×/5×/20×、拖曳滑桿），可用 S/M/L 切換大小（記在瀏覽器），再點一次收起。一天約 30 分鐘（不與現實時間綁定）。
- **樓層按鈕**：點 5F…1F 會顯示該層**以及它下面所有樓層**（只隱藏上面的樓層，下半部不會空掉），鏡頭對準被選的那層、按鈕亮起；2F、1F 按鈕標「船艙」（水線以下的船殼層，剖面顯示）；點「全景」回到整艘船。
- **角色**：沿用上一版辦公室的 Kenney Mini Characters（CC0）方塊小人與骨架動畫（走路/坐下打字/玩耍/睡覺/游泳…）；T董戴皇冠、西裝金領帶，名牌特別放大。
- 👥 **成員清單**：點成員即可把鏡頭聚焦過去（對應辦公室的列表模式）。
- 網址參數（除錯 / 截圖用）：`?q=low|mid|high` 鎖定畫質、`?t=0.74` 時間、`?mode=overview|free|follow`、`?cam=yaw,pitch,dist,x,y,z`、`?demo=1` 離線示範資料、`?demo=cycle` 每 30 秒輪替工作/休息/下班、`?explode=5`。


## 新手教學任務與廢土美術（2026-10）
- **教學任務**（右側面板，可收合/關閉；詳見 `DESIGN-quests.md`）：基本操作（走動、和船員說話、開海圖、出航）與經營（打撈、補給、升級小船、造船）兩條線，共 8 步，每步一次性發獎勵（不可刷）。獎勵合計 食物 760／飲水 880／燃料 880／零件 240 ＋ 最後一步一張稀有藍圖，約等於 2～3 天的消耗；開局資源不變。進度存在選填欄位 `quest`（`SAVE_VERSION` 仍為 1，舊存檔照常載入）。
- **小船成長**：船身隨等級放大（Lv1/2/3 = ×1／×1.14／×1.28），發電機/醫療室/工坊改為艙口（平貼地板可走），甲板只留淨水器與溫室；`tools/walk-small.cjs` 讓角色走過 5 種船 × Lv1–3 全部站位。
- **廢土美術**：鏽斑/鏽流/掉漆、焊接補丁板、鉚釘、輪胎護舷、土法天線與屋頂零件、混濁海水、油膜、漂浮殘骸，全部程式生成；網址加 `?wl=0` 可看舊畫面。

## 內容（Phase 1）

- **郵輪 5 層：上三層 + 船殼內兩層**（可逐層顯示 / 展開）：5F、4F 為上層建築（逐層退縮），3F 是**主甲板**（救生艇、躺椅、起錨機、船艏船艉甲板；辦公區在玻璃牆內），**2F、1F 在船殼內**——船殼外側有兩排**舷窗**（夜晚亮燈），單獨顯示 2F / 1F 時外殼會「剖開」，只留舷側矮艙壁並有艙內燈光。樓梯與電梯貫穿全部 5 層。  
    5F T董辦公室、觀景台、直升機坪、大煙囪與雷達桅杆、按摩池、**競技場電視**；4F 泳池、水上滑梯、街機、吧台；3F（主甲板）交易員-1 / 交易員-2 對坐、其他同事座位、會議室＋第二台競技場電視；2F（船殼內）匹克球、籃球、桌球、健身房、跑道、醫務室、船艉 SPA、船艏休憩艙；1F（船殼內）每位 bot 一間艙房（床＋獨立浴室）、餐廳廚房、倉庫、船艏錨鏈艙。
- **海洋與時間**：shader 浪、船隨浪搖晃；日出/白天/日落/夜晚、星空、月亮，燈光/霧/水色隨時間變化。
- **海洋生物**：成群躍出的海豚、浮出噴水的鯨魚、飛魚、海鳥、漂流殘骸、遠方半沉的廢墟大樓與斷橋。
- **船員（即時資料）**：讀取辦公室公開的 `sessions.json`（唯讀、約每 45 秒輪詢，實際資料約 2.5 分鐘更新）：
  - 工作中 → 3F 座位敲鍵盤，偶爾去倒咖啡 / 喝水 / 白板 / 看海。
  - 休息中 → 4F / 2F / 5F 休閒；兩位閒人會配對打**真的乒乓 / 匹克球**。
  - 下班 → 回 1F 自己的艙房：**關上浴室門、蒸氣瀰漫，穿浴袍出來**，然後睡覺。
  - 交易員頭上顯示權益 / 損益 / 持倉氣泡。
- **心情與聊天**：心情（開心 / 專注 / 疲累 / 焦慮 / 無聊）由狀態、連續工時、時段與交易員損益推得，頭上顯示表情＋偶爾的「心情小語」。靠近的船員會用模板對話輪流冒泡（工作、天氣時段、競技場、球賽、兩位交易員互相調侃）。**不呼叫任何 LLM。**
- **畫質**：高 / 中 / 低；手機預設中 / 低，FPS 過低時自動降級（右上角可手動鎖定）。

## 玩法（Phase 2 + 雲端存檔）

- **資源列**（左上）：🍖食物 💧飲水 ⛽燃料 🔩零件 + 🛠船體狀況，旁邊顯示每分鐘淨變化；下方是精簡船員列（點一下走過去）。📋 每日任務、🚣 出海探索。
- **建造 / 升級 / 修理**：走近設施（淨水器、溫室、發電機、醫療室、工坊）按 **E**（手機：點提示面板的按鈕；也可點設施標籤自動走過去）。最高 Lv3；風暴會讓設施故障，需要修理；工坊可整修船體。
- **船員互動**：走近船員可 💬聊天（回應會參考心情與船上狀況）、👀看心情、💖打氣（有冷卻；只影響遊戲內小人的心情）。
- **出海探索**：派 1–3 位船員駕救生艇去撈沉船殘骸；三種風險（低 3 分鐘 / 中 15 分鐘 / 高 60 分鐘），收穫越多、受傷機率越高；受傷者需要休養（醫療室縮短）。出海的船員會從船上消失、小艇會真的駛向海上，返航後回到主甲板。
- **你不在的時候**：進遊戲時依「上次存檔時間」用同一套決定性模擬補算（最多 48 小時），顯示生產/消耗、事件、受傷、出海成果；另有 3 個每日任務（本地 00:00 重置）。
- **真實 bot 狀態只給一點點加成**：駐守某設施的 bot 若在「上班」+10%、「休息」+5%（唯讀、僅顯示；不影響進度判定，也不會傳送任何東西給 bot）。
- **📷 攝影模式**：下方時間軸只改變畫面光線與時段，**不影響遊戲時間／進度**；遊戲進度完全以現實時間計算。
- **Google 登入 + 雲端存檔（Firebase）**：右上角 🔑 登入（popup；被擋或環境不支援才改 redirect）。登入後進度存在 Firestore `arks/{uid}`（每人一座自己的方舟），同時在本機留一份鏡像 `ark.cache.{uid}`；訪客照樣能玩，進度存 `localStorage`（`ark.save.v1`）。
  - 首次登入：雲端是空的 → 詢問是否上傳本機進度；兩邊都有 → 顯示小視窗讓你選（預設較新的）。
  - 存檔：每 10 秒收集、雲端最短 30 秒寫一次（免費額度友善），切到背景 / 關閉頁面時立刻寫。離開後再回來用同一套模擬補算。
  - **防竄改時鐘**：登入時遊戲時鐘以「伺服器時間」為錨（Firestore `serverTimestamp` 讀回），之後用 `performance.now()` 推進，所以改裝置時鐘無效；連不上伺服器時離線補算最多承認 30 分鐘。訪客只能用裝置時鐘（localStorage 本來就能改）。
  - **船東**：只有 Firebase uid 列在 `src/save/cloud.js` 的 `OWNER_UIDS` 裡的帳號（只認 uid，不放 email；uid 可在 🔑 選單最下方複製）看得到真實 bot 與交易電視並抓取 `sessions.json`；其他帳號與訪客只有虛擬船員，電視顯示「僅限船東頻道」。這只是顯示判斷（`sessions.json` 本來就是公開檔案），不是安全邊界。
  - **進站流程**：新瀏覽器（沒登入、沒選過模式）先看到第一畫面 [用 Google 登入] / [訪客遊玩]（`src/ui/entry.js`，上次選擇記在 `ark.mode`）。只有船東帳號登入才載入 T董 的遊輪方舟與真實 bot（雲端存檔）；訪客與其他 Google 帳號都從選船開始（小漁船 / 洋流號 / 打撈拖船）、虛擬船員。訪客存檔在本機；非船東登入時可選擇上傳訪客進度，船東永遠載入雲端方舟、不合併訪客進度。本機若殘留船東（T董）存檔，非船東一律忽略並備份到 `ark.ownerLocal.v1`。🔑 選單：登入 / 登出 / 切換為訪客。
  - Firestore 規則見 `firestore.rules`（只能讀寫自己的 `arks/{uid}`，有大小 / 形狀檢查，其餘全拒）。部署：Firebase 控制台 → Firestore → 規則，貼上後發布。
- **登船 API（預留，未開放）**：`src/api/boarding.js` 定義「bot → 方舟」單向唯讀的狀態格式（名稱 / 狀態 / 類型），沒有端點、沒有規則、沒有任何程式呼叫它。
- 網址參數（除錯 / 截圖用）：`?q=low|mid|high` 鎖定畫質、`?t=0.74` 時間、`?mode=overview|free|follow`、`?cam=yaw,pitch,dist,x,y,z`、`?demo=1` 離線示範資料、`?demo=cycle` 每 30 秒輪替工作/休息/下班、`?explode=5`。

### 模擬核心（`src/sim/`）

純函式、無 DOM / three.js：固定 60 秒一個 tick，每格亂數由 `hash(seed, tick)` 決定，所以「離線一次補算」與「線上逐格推進」結果相同。出海結果在出發時由 `hash(seed, 'trip', id)` 預先決定。`node tools/sim-test.mjs` 跑 17 項決定性/平衡測試；瀏覽器內 `ark.selfTest()` 會一併檢查（回傳 `[]` = 正常）。`node tools/save-test.mjs` 測存檔開機邏輯 / 雲端轉接器 / 時鐘防竄改 / 船東判定（記憶體後端，不連網）。開發模式可用 `?fakecloud=owner|user|guest|offline`（只在 `npm run dev`）模擬登入。

## 資料與隱私

- 唯一的外部請求：`GET https://tt0xcatyi.github.io/grokbot-office/sessions.json`（CORS `*`）。**不會對任何 bot 傳送任何東西。**
- 進遊戲前只保留名稱 / 狀態 / 類型 / 競技場權益數字（`src/data.js` 的 `normalize`），路徑、金鑰、備註一律丟棄。
- 交易競技場只出現在兩台電視上，與遊戲玩法完全分離。
- 連不上時自動切換到「離線示範資料」。

  world/           waves、environment（天空/光/霧）、ocean、sealife

  crew/            avatar、actor（跨層路徑）、crew（行為狀態機）、match（球賽）、mood、chatter

### 後續階段的掛載點

- `registerSystem({ update(dt, game) })`：資源、派工、建造、離線放置進度、危機事件等系統。
- `events.js` 的 `emit/on`：`data`、`crew`、`elevator`、`time`、`quality` 事件；Google 登入 / Firebase 雲端存檔可訂閱這些事件。
- `Crew.applyData(data)` 的輸入格式即「船員狀態」：之後給其他人 AI bot 的 **唯讀 boarding API** 可直接餵同一格式（虛擬船員）；好友方舟 = 另一個 `Game` 場景 + 虛擬船員。
- 末日危機（船永不沉、只會殘破並自我修復）：`Ship` 的材質/`waveState.amp` 已可外部調整；拾荒船、海盜 / 海怪可沿用 `SeaLife` 的生物生成模式。

## 已知限制

- 無頭瀏覽器（swiftshader）只有約 10–15 fps，實機 GPU 會順很多；請以真機為準。
- 5F 直升機坪僅為裝飾（不可走上去）。
- 球賽 / 游泳等動作為程序動畫，細節（手指、衣物物理）刻意簡化。

## 船體設定（src/ship/config.js）

`SHIP` 集中了船名、半寬、龍骨、船艏長度、各層外形、層高與「兩端壓縮」參數；`HULL` / `PARAMS` / 海面泡沫 shader / 俯瞰鏡頭中心都由它導出。
佈局原本以舊版 106 m 長船的絕對座標手工擺放，縮短的方式是：中段（`sternEdge`~`bowEdge`）原封不動，兩端的景觀甲板依 `sternK` / `bowK` 壓縮，
端部裝飾的 x 座標以 `ex(x)` 轉換。調小 `sternK` / `bowK` 就能更短（裝飾會變擠）。目前全長約 91 m（舊版 106 m）。
日後的艦隊船型，只要提供另一份 SHIP 設定即可。

## 艦隊（Milestone 3）
按 ⚓（或 `F`）打開艦隊面板：6 種船（小漁船／快艇／打撈拖船／潛水艇／武裝巡邏艇／破冰船），可建造（資源＋藍圖）、升級 Lv1~3、檢視 3D 模型、設定目標海域；小船在你離線時也會自動出海帶回資源與稀有藍圖。非 Tim 的帳號第一次進來要先選一艘小船。資料模型與未來地圖／PvP 設計見 [DESIGN-fleet.md](DESIGN-fleet.md)。測試：`node tools/fleet-test.mjs`。

## 大世界、海圖與駕駛（Milestone 4）
- 世界 2000×2000，5 個區域（近海／珊瑚礁／廢墟城市／冰海／深淵），戰爭迷霧；每位玩家依 uid 決定性出生在相距 ≥600 的 8 個出生點之一（`src/sim/world.js`）。
- 🧭 海圖（按 `M`）：拖曳／縮放，點選目的地讓方舟航行（離線也會繼續走，結果與線上一致）；任務在海上遇到事件時可在海圖上選擇（預設自動處理，不選也不影響閒置模擬）。
- 🛳️ **駕駛母船**（`G` 或資源列的 🛳️）：直接操控「家」那艘船本身（T董 的郵輪方舟／訪客的小旗艦），跟走路的 T董 互不相干——船員照常在甲板上走動。
  - 操作：`W`/`S`（或搖桿上下）調**油門**（放開後保持，`空白鍵` 停車、`Shift` 加速），`A`/`D`（或搖桿左右）打**舵**；舵效隨船速、有慣性（收油後慢慢滑行）、轉彎時船身傾斜、船尾拖出尾流；鏡頭自動繞到船後（拖曳可手動轉，2.5 秒不動又會回到船後）。底下的駕駛列顯示航速（節）、航向、海圖座標、油門，並有 ⏹ 停車 / ⚓ 下錨（退出）按鈕；手機用搖桿 + 這兩個按鈕。
  - 與海圖一致：駕駛只是「當前地圖位置」周圍的本地操船；船的位移 × `HELM_K`（`src/play/helmphys.js`，滿速 11 m/s 剛好等於自動航行的 1.2 單位/分鐘）會累積推動 `fleet.world.pos`、揭開迷霧、少量耗油；開出去再開回來，地圖位置也跟著回來。開始駕駛會先取消自動航線；在海圖按出航則自動退出手動駕駛；推到世界邊緣會停船。艦隊的其他船、出海探索的小艇都以母船座標系跟著走。
  - 訪客的旗艦出海任務中不能駕駛（等它回來）；駕駛母船和「駕駛出海小船」互斥。
- 🎮 從艦隊視窗按「駕駛」，T董 會登上小船繞著方舟開，撿海上漂浮的箱子，🏠 返港結束。
- 快艇換成新造型「洋流號」（橘色圓胖漁船，帆上「順」、船尾旗「洋流」，皆為程式生成的 canvas 貼圖）。
- 特別版吉祥物「奔奔」與「抱抱」每隔幾分鐘隨機出現在某層甲板，跑一陣子後以星星離開；走近按 `E`（或點名牌）可互動，附近船員心情暫時變好。純裝飾，不入存檔（`src/crew/mascots.js`）。

## 小船之家（訪客 / 非擁有者）
- 擁有者（T董，雲端存檔）看到的是郵輪方舟；**訪客與其他 Google 帳號完全看不到方舟船體**。
- 選船前只看到海面（選船時預覽目前點選的那艘）；選好後家 = 自己的小船（🛶 小漁船 / ⛵ 洋流號 / 🚢 打撈拖船，之後可在艦隊面板用 ⭐ 設為旗艦換成巡邏艦、破冰船）。換旗艦 / 升級旗艦會存檔後重新載入場景。
- 小船只有一層甲板（`src/ship/homespec.js` 純資料＋排版：桌子、座位、聊天點、欄杆、躺椅、5 個設施的小型版本，排完會用 NavGrid 驗證每個點走得到；`src/ship/smallship.js` 場景物件）。船員人數受載員上限限制（小漁船 3、洋流號 4、拖船 6、巡邏艦 6、破冰船 8）。
- 甲板按鈕 / 數字鍵 1–5 會隱藏不存在的樓層；資源列、艦隊、海圖、駕駛、吉祥物照常運作。
- 測試：`node tools/home-test.mjs`（5 種船的排版可達性 + 旗艦邏輯）、`node tools/home-map.mjs`（印出 ASCII 排版圖）。
- 小船的工作桌放不下標準桌時會改用**精簡桌**（1.0×0.6 m，`FP.deskC`），所以每艘船都坐得滿；小船上人物標籤的距離分級較緊，船尾不再擠成一團。
- 測試：`node tools/walk.cjs`（需先 `npm run dev`；用無頭 Chrome 讓 T董 走到每個設施、遊樂點與每位船員旁）。

## 遊玩與船員互動
- **計時小遊戲**：走到遊樂設施（匹克球、桌球、籃框、街機、吧台、跑步機、舉重椅、躺椅、跳水、溜滑梯、泡湯）按 `E`（手機點提示按鈕）；指針掃進綠色區塊時按 `E` / 點一下。成績有星等與個人紀錄（`rel.best`）。
- **邀請**：旁邊有船員時可以邀請同玩，對方依心情 / 工作 / 交情接受或婉拒（同一分鐘答案固定）；一起玩會增加交情，匹克球 / 桌球是真的和船員對打。
- **船員之間**（`src/crew/social.js`、`src/sim/rel.js`、`src/crew/rellines.js`）：兩兩交情 → 好朋友 / 對頭；會吵架、冷戰、再和好；朋友優先互相約球、對頭下戰帖；閒聊對白依關係而不同。
- **聚會**：每天 3 餐在餐廳同桌（朋友同桌）、夜間派對、大豐收慶祝；風暴 / 受傷時船員會聚過來幫忙。氣氛好駐守效率小幅 +，冷戰時 −。
- **💞 關係面板**（`R`）：你 ↔ 船員、好朋友、對頭 / 冷戰倒數、團隊氣氛、個人紀錄。
- 存檔：`rel` 為選填欄位（`aff / feud / cool / party / cel / best`），舊存檔相容；離線模擬仍是決定性的。遊戲對 bot 唯讀，不會傳送任何東西。
- 備註：遊輪上沒有卡拉 OK，因此沒做；訪客的小船沒有大型設施，只有躺椅與社交 / 關係功能。
